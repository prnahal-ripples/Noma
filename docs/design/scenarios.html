Corner smoothing

100%
border-radius · circular
squircle · 100%

Corners are smoothed the way iOS smooths them — a superellipse, not a circular arc — and that is a large part of why the shapes read as premium rather than merely rounded. Owner, 2026-08-19: 100%, the full iOS value. The two squares on the right are the same size and the same radius; only the corner differs. Look at where each one stops being straight — the smoothed one starts turning much earlier and never has a hard tangent point. These prototypes now render it. border-radius can only draw a circular arc, so docs/_squircle.py emits Figma’s own corner geometry as a 9-slice mask that restretches at any element size. Native takes .continuous.
